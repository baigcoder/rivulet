Yours

It ships with nowhere to look

Rivulet hosts no content and indexes no content. A source is a URL you add. With none configured it is still a torrent client with a very good player.

Empty on purpose

No default, suggested, or bundled source list. Deep links always ask before adding anything. HTTP JSON only — no plugin runtime.

The library stays here

History, progress, favourites, and the watchlist live in this device’s storage. One backup file moves them. There is no account.

Nothing phones home

No analytics, no telemetry, no crash reporter. Credentials stay in the source URL you pasted. Backup files skip those keys.

This project does not host, run, bundle, endorse, or recommend any source, and distributes no list of them. What a given source offers, and whether you have the right to play it, is between you and whoever operates it.

FAQ

The questions that keep coming up

Does Rivulet provide content?

No. It hosts no content, indexes no content, and ships with no sources. It is a local library and player for files and URLs you choose to add.

Do I need a source at all?

No. Magnets, .torrent files, and local video play without one. A source is only for searching releases you do not already have.

Why is there no default source?

Bundling someone else’s catalog would pick a side. You type a URL you found yourself. That is the whole onboarding flow.

Does it work on a TV?

Yes. The Android APK is a leanback build: d-pad navigation, 10-foot scale, and a performance switch for weak GPUs.

What plays on Android?

libVLC, not the webview’s video tag. Landscape and immersive while a title is up. Background downloads stay alive through a foreground service.

macOS says the app is damaged. Is it?

No. Gatekeeper says that for unsigned GitHub builds. In Terminal: xattr -cr /Applications/Rivulet.app

Watch while it downloads, or play a link now?

The playback-source setting. On: the torrent engine, an offline copy, full codecs. Off: only direct HTTP links — instant start, no disk, no swarm. You can flip it on a title that is already playing.

Why Tauri instead of Electron?

The OS webview and a Rust shell: a smaller binary, less RAM, and a real native window to glue mpv into.
